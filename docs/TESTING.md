# テスト手順

## 適用範囲と実行方針

iOS Simulator上で実行する単体・回帰・UIテストすべてに、この運用ルールを適用する。記録、所有確認、清掃、報告はテストを実行した開発エージェントが行う。自動清掃スクリプトの実装は不要。

実装中は必要な対象テストに絞り、最終変更後に必要な全体テストを実行する。変更・失敗・未解決の確認事項がない状態で、全体テストを繰り返さない。

## 通常実行と並列実行

通常は既存のSimulator端末1台を再利用する。`xcodebuild test`および`xcodebuild test-without-building`には、対象端末のdestination指定とともに、次のオプションを必ず指定する。

```sh
-parallel-testing-enabled NO -maximum-concurrent-test-simulator-destinations 1
```

同じ端末へのテストを同時起動しない。他の作業で使用されていないことを確認してから実行する。

並列実行が必要な場合は、実行前に理由を明示する。通常の逐次実行設定を変更し、`-parallel-testing-enabled YES`を使用する場合も、`-parallel-testing-worker-count`と`-maximum-parallel-testing-workers`を2以下に設定し、`-maximum-concurrent-test-simulator-destinations`も2以下に制限する。worker数は最大2とする。並列数の制限だけでは残存端末の蓄積を防げないため、以下の記録と清掃も必ず行う。

## 実行前後の記録

テスト実行前と、テストプロセスおよび子プロセスが終了した後に、次のコマンドでXCTest用device setの端末ID（UDID）を記録する。

```sh
xcrun simctl --set ~/Library/Developer/XCTestDevices list devices -j
```

取得結果のJSONと取得成否を、実行を識別できる記録として保存する。実行時刻、実行コマンド、対象端末ID、プロセスの識別情報、作成元を確認できるテストログなども保存し、中断後も参照できるようにする。取得失敗を「端末なし」や空の一覧として扱わず、失敗を記録・報告する。所有確認に必要な記録を取得できない場合は、推測による削除を行わない。

端末名や実行前後の差分だけで、自分の実行が作成した端末と断定しない。差分は候補の抽出に使い、実行記録やログなどから自分の実行による作成を確認する。他の実行と重なった場合や作成元が不明な場合は削除せず、候補IDと確認できなかった理由を報告する。

## 実行後の清掃

テストの成功・失敗にかかわらず、次の順序で清掃する。

1. テストプロセスと子プロセスがすべて終了したことを確認する。終了を確認できない間は削除しない。
2. 保存した記録を照合し、自分の実行で作成したと確認できる複製だけを削除候補にする。
3. 削除直前に、同じdevice setの`list devices -j`を再取得し、対象UDIDが停止中（`Shutdown`）であることを再確認する。取得失敗、状態不明、起動中の場合は削除しない。
4. 所有と停止状態を確認できた複製を、同じdevice setを指定して個別に削除する。

   ```sh
   xcrun simctl --set ~/Library/Developer/XCTestDevices delete <UDID>
   ```

5. 同じdevice setの`list devices -j`を再取得し、削除対象IDが消えたことを確認する。削除コマンドの成功だけで清掃完了と判断しない。再取得に失敗した場合は、削除確認未完了として報告する。

通常端末、起動中端末、他の作業の端末、OSランタイム、テスト結果・ログは削除しない。`delete all`やディレクトリの直接削除は使わない。清掃のために起動中端末を停止して削除対象にすることも避ける。

中断で清掃できなかった場合は、次回に保存した実行記録を確認する。その記録から自分の実行による所有と、削除直前の停止状態を確認できる複製だけを清掃する。確認できない端末は残して報告する。

## 清掃結果の報告

削除後の確認結果に基づき、削除数、清掃候補の残存数とID、清掃失敗および確認未完了の内容を報告する。所有不明・他の実行との重複・起動中などの理由で残した候補も明示する。一覧の取得失敗時は残存数を「不明」とし、0件と報告しない。

`du`で測った容量を、そのまま回復した空き容量として報告しない。空き容量の回復を報告する場合は、空き容量を別途測定し、測定値とその限界を明示する。
