# 共有メモ実装プロンプト

既存のiOS・Webメモアプリを維持し、Googleログインと既存のFirestore group001を使う共有クリップボードへ段階的に拡張する。対象はiPhone、Mac、Windows、Web。

1. 既存iOSビルド、永続化・削除復元、Markdown表示を確認し、保存中・保存済み・失敗を正しく表示する。
2. 用途は一時／保存、機密は独立したbool、固定は既存のpinnedを利用。旧メモは保存扱い、新規は一時扱い。旧クライアントが編集しても新項目を保持。機密はラベルで、一覧や検索で本文を露出しない。暗号化や専用ロックは追加しない。
3. タイトル不要の一時メモと最新順表示、本文コピー、手動ゴミ箱移動を提供。自動削除・クリップボード監視はしない。
4. メモ／プロンプト／コマンド／コード片を指定でき、改行・字下げ・末尾#をそのまま保存・コピー。コマンドは実行しない。従来エディターを残す。
5. iOS共有拡張で文章・URLを確認して保存。既存Googleログインを共有Keychainで利用し、権限・失敗表示を維持する。
6. Webを基にMac/Windows用常駐アプリを作り、トレイ、表示/非表示、グローバルショートカットを提供。Googleログインはシステムブラウザを使い、権限を最小化する。

各段階で必要な回帰検証を行い、既存データを一括変換しない。Firestore Rulesの許可対象を変えず、任意の新項目を型検証する。ソース、検証結果、配布物を記録し、検証が通ったWebとRulesを既存公開先へデプロイ。iOSおよびデスクトップの署名・実機条件による未確認事項は明示し、未検証を完了と報告しない。
